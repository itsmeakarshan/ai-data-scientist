# AutoDS Champion Model Storage

This directory holds serialized champion machine learning model artifacts generated by the AutoDS pipeline.

## Artifact Structure
- **Format**: Joblib serialized model estimators (`{analysis_id}_{model_name}.joblib`)
- **Metadata**: Associated preprocessing configuration, feature schema, out-of-fold validation metrics, and touchless holdout evaluation results are persisted in the AutoDS database (`ModelRecord` and `AnalysisRun` tables).
- **Explainability**: SHAP explanations and TreeSHAP/Linear attribution rankings are saved in `ModelRecord.shap_summary_json` and `ModelRecord.feature_importance_json`.
